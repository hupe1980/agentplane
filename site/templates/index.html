Durable execution · Deterministic replay · Policy-governed

The journal is the plan of record.

An agent runtime in Rust where every outward call is written down before it happens. Crash mid-run and resume from the last completed effect. Replay a run and perform nothing. Prove afterwards what occurred — and that the record was not edited.

What goes wrong without it

  • A 40-minute run dies at minute 38, and the retry re-issues every invoice.
  • “Why did the agent refund €4,200?” has no answer, because the reasoning was a log line that scrolled away.
  • Untrusted tool output steers the next tool call.
  • A prompt change ships with no way to know what it broke.

What it gives you

A journal you can audit

Append-only and hash-chained, with per-record signatures naming the workload that wrote them, and a per-plane Merkle log so deleting a whole run is detectable.

Durable execution

Resume from the last completed effect. A suspended run costs a row on disk, not a thread — so a plane can hold 10⁵ of them waiting for a human.

Exactly-once, honestly

Enforced by the store, not by a code path someone might forget. A call whose outcome is unknown is never blindly retried and never quietly unwound.

Information-flow labels

May this principal act and may this value go there are different questions. Untrusted data cannot reach a mutating sink without a typed, policy-authorized, journaled release.

Human oversight that binds

Durable worklists with four-eyes, declared expiry behaviour, and an operator who can stop a run and have it unwind.

Erasure that keeps the proof

Drop a payload's bytes and the chain still verifies — it only ever committed to a digest. A later read says expired, on this date, for this reason, never missing.

A witness that refuses

A checkpoint is cosigned only if it provably extends the last one seen. A shrunken log is rejected, and so is a second history of the same size — the split view.

Cases, not long-lived workflows

Runs stay minutes; business processes span months. A deploy never has to migrate an in-flight workflow.

Why you should believe any of it

Guarantees are only worth what their tests can falsify — so each one is broken on purpose, and the test written for it must fail.

Thirty seconds

cargo add agentplane
let store: Arc<dyn JournalStore> = Arc::new(RedbStore::open_in_memory()?);

let runtime = Runtime::builder(Arc::clone(&store))
    .owner("my-service")
    .skill(Triage)
    .build();

let out = runtime.run("ticket.triage", json!({ "text": "printer on fire" })).await?;

// Re-executes the logic and reads every effect back. Nothing is performed again.
let replayed = runtime.replay(out.run_id, Mode::Strict).await?;
assert_eq!(out.output, replayed.output);
